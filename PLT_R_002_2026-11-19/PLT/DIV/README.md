# DIV：羊毛索引树聚类

## 活动接口

`PLT.DIV.cluster_quantized_pixels(width, height, palette, pixel_indices, integral)` 返回一个 `PLT.model.Candidate` 元素的元组。索引图已由 TOP 在智能亮度倍率下量化到配置羊毛色板；palette 项数可为任意正整数，不要求是 2 的幂。

## 树结构与聚类

- 将图像左上对齐放入 `next_power_of_two(width) × next_power_of_two(height)` 的矩形树根；树内外侧用 `-1` 哨兵，不扩大最终输出图像。
- 每一层若宽、高都大于 1，则四叉划分为四个等尺寸子节点；若只有一个轴大于 1，则沿该轴二叉划分。树自动细化至 1×1 像素单元，不设 `max_splits`、候选预算或人工搜索深度。
- 自叶节点向根节点检查：只有所有有效子节点均匀且 block_id 相同时才合并。否则保留各子树继续向上。
- 输出最大同色树节点为矩形分区。节点尺寸是树的 2 幂跨度；哨兵区域不输出，所有原图像素恰好覆盖一次。
- 每个节点只引用原调色板项，不平均/创建新颜色；聚类不改变量化后的 block_id 栅格。Candidate D 通过 D 的积分图对未缩放原 RGB 计误差，等于逐像素羊毛量化误差。

## 完整性与隔离

DIV 验证索引数组 shape、palette 索引范围、共享模型和图片积分图尺寸。`segmentation.py`/`DIV.model` 的旧实验 API 仍从 R_001 复制保留，不参与 R_002 活动路径。
